Start with a shelf

Imagine three books on a shelf. The shelf is the parent. The books are its children. Give the parent a Flexbox layout, and it can arrange all three books at once.

.shelf {
  display: flex;
  justify-content: space-between;
}

HTML & CSS reference

Tags, styles and publishing
  • Put visible content in <body>. Give the page an <h1> heading, use <p> for a paragraph, and nest <li> items inside <ul> for a bulleted list.
  • An image uses src for its file and alt for its text alternative. A link uses <a href="…">. A note between <!-- and --> is an HTML comment.
  • Placed in the head, <link rel="stylesheet" href="styles.css"> connects pages to shared style rules. color changes the letters. background-color changes the area behind them.
  • A digital footprint can include posts or photos that others save. Use artwork you created or have permission to use, follow its license, ask people before publishing their pictures, and keep personal addresses private.

Move a sprite with a condition

A sprite is an object that can move on a screen. A game can check for key input on each frame. Our grid runner takes one step per keypress. If you start at x = 2, pressing right moves you to x = 3.

if (keyDown("right") && player.x < 4) {
  player.x = player.x + 1;
}

Predict. If the sprite is at x = 4 and you press right, what should happen? Move the runner to the flag, try the edge, then turn the corner. Row 0 is at the top.
